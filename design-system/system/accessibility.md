# Accessibility

Target: WCAG 2.2 AA.

## General

- Interactive elements must have an accessible name.
- Keyboard interaction must be supported.
- Focus must remain visible.
- Do not communicate information using color alone.
- Form controls must have associated labels.
- Icon-only controls require an accessible name.
- Disabled states must be communicated programmatically.
- Error messages must be associated with their controls.
