# Avatar usage

## Use

Representa una persona con una imagen o una sola inicial. Escoge el tamano y la forma segun el contexto.

## Do not

- Usa una sola letra para `initials`; Figma indica que varias letras pueden desbordar.
- No recrees el avatar con estilos ad hoc si ya existe este componente.
- No anadas variantes que no esten registradas en Figma y en el DS.
