# Composition rules

- Use existing DS components whenever a matching component exists.
- Use spacing tokens for layout gaps.
- Do not nest interactive elements inside other interactive elements.
- A primary action should be visually unique within the same action group.
- Do not introduce a new layout primitive if an included DS component already provides that grouping.
